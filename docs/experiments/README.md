# Historical experiments

These reports record scoped prototype experiments and their review outcomes.
Dates, model digests, memory measurements, source hashes and test results describe
the measured run, not the current deployment or a general capability guarantee.
Use the current GitHub test workflow for current software validation.

Published task-owner fields use the generic pseudonym `operator`. This replaces
the original local principal label without changing task IDs, model results,
source access audits or measured outcomes. The reports are curated publication
artifacts, not raw private task database exports. Generated code and proposals
remain untrusted and may intentionally include rejected or incorrect examples.

Private credentials, live task databases, process logs and recovery snapshots
belong in ignored private storage. Do not add them to this directory.
